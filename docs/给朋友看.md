# 桌面宠物 — 给朋友的安装说明

你**不需要**装 Python。

## 一步搞定（请下 zip，不要直接下 .exe）

1. 打开 [Releases](https://github.com/witguang/desktop-pet/releases)
2. **只下载** **`DesktopPet-v*-windows.zip`**  
   - ⚠️ 不要点单独的 `DesktopPet.exe` 附件（浏览器常会拦截「通常不会下载 .exe」）
3. 解压 zip → **双击里面的 `DesktopPet.exe`**
4. 首次弹出设置（安装位置、备忘录、快捷方式、是否打开桌宠）  
   - 会**提醒建议放在 D 盘**，路径需自己选  
   - 快捷方式 / 打开桌宠默认勾选，可取消

安装目录正常只有 **一个 `DesktopPet.exe`**（用一阵后会有 `data_store`，可忽略）。

---

## 浏览器提示「通常不会下载 DesktopPet.exe」？

这是 **Edge / Chrome 对「不常见、未签名的 .exe」的默认保护**，不是病毒报错。  
**正确做法：改下 `.zip`，不要直接下 `.exe`。**

若你已经点了 exe 下载：

| 浏览器 | 怎么放行 |
|--------|----------|
| **Edge** | 下载栏 → 文件旁 **…** → **保留** → **显示详细信息** → **仍要保留** |
| **Chrome** | 下载栏 → **˅** → **保留** → **仍要保留** |
| 下载后被删 | 浏览器设置里看「下载内容」是否被安全功能清掉，改下 zip |

---

## Windows 提示「已保护你的电脑 / 未知发布者」？

这是 **SmartScreen**（程序没有「代码签名证书」，下载量也不够信誉）。

1. 点 **「更多信息」**
2. 再点 **「仍要运行」**

若右键属性里有 **「解除锁定 / Unblock」**，勾选后确定再运行。

> 彻底消除此提示需要开发者购买 **Windows 代码签名证书** 并给 exe 签名。开源小工具未签名时，上述步骤属于正常使用方式。

## 其它注意

| 情况 | 处理 |
|------|------|
| 想开机自启 | 右键桌宠 → 主设置 → 开机自启 |
| 卸载 | 退出桌宠 → 删除安装文件夹 → 删桌面/启动项快捷方式；备忘录目录可保留 |
| 数据在哪 | 安装目录 `data_store/`；备忘录在你选的文件夹 |

## 操作

| 做什么 | 怎么做 |
|--------|--------|
| 移动 | 左键拖 |
| 控制面板 | 右键，或 `Ctrl+Shift+P` |
| 退出 | 控制面板 / 主设置 → 退出桌宠 |
